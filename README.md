## lfl-analyzer

### Roadmap

1. Статистики
   1. Передачи в статистике
   2. Возраст и замены(состав) через сезоны и список матчей
   3. Состав в отчете по недавним матчам
   4. Очки команд табличкой
2. Сортировка
   1. Рендер таблицы руками (а не через pandas)
   2. Несортируемые колонки
   3. Отображение дефолтной сортировки
   4. Сброс сортировки
3. Парсинг HTML
   1. Возможно - для передач (?)
   2. Стата в дивизионе
   3. build-id с page.lfl.ru
   4. Параметры для отчета
4. CLI (скорее всего с конфигурационным файлом)
5. Авто-публикация gh-pages
6. Лучший расчет вероятности приезда и силы
7. Ручные заметки
8. Отчеты с фотками
